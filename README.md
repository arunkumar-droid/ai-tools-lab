## Folder structure

```
ai-tools-lab/
  README.md
  tools/       # har tool ki notes file
  examples/    # har tool ke real example, screenshots, code
  docs/        # git setup aur extra notes
```

## Workflow (har tool ke liye)
1. `tools/` me us tool ki file kholo
2. README padho, setup karo (safe folder / sandbox me)
3. Ek real task do, output save karo `examples/<tool>/` me
4. Learnings aur verdict likho, is README me Status update karo
